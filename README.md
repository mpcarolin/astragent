## Getting started

### Prequisites
* Node `24.21.0` or newer
* [pnpm](https://pnpm.io/)

### Start the dev server

```sh
pnpm install
pnpm dev
```

Visit http://localhost:5173 in your browser.
* Scroll to zoom in and out
* Click and pan to look around
* Click on the label of any planet to zoom into that planet
